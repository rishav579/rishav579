## Engineering principles

- **Reliability over demos:** evaluate behavior, handle failure modes, and make systems observable.
- **Security by design:** enforce authorization at retrieval and action boundaries, not just at the UI.
- **Human control where it matters:** use bounded autonomy, approvals, and audit trails for consequential actions.
- **Product thinking:** optimize for user outcomes, latency, cost, and maintainability—not model novelty alone.
